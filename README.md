# 🎁 쿠팡 제휴 콘텐츠 자동화 (쓰레드 글 + 카드뉴스)

> 쿠팡 파트너스 링크 **하나만** 넣으면 → 쓰레드 글 + 카드뉴스 10장이 자동으로 나옵니다.
> 오토워커 2기 무료특강 보너스 · 문의는 카톡방에서

---

## 0. 준비물

| 준비물 | 설명 |
|---|---|
| Claude Code | 무료특강 실습에서 설치한 그대로 사용 |
| Python 3.10+ | 없으면 Claude에게 "파이썬 설치해줘"라고 하면 안내해 줍니다 |
| Chrome 브라우저 | 일반 크롬이면 됩니다 |
| 쿠팡 파트너스 계정 | https://partners.coupang.com 가입 (승인까지 1~2일) |

**⚠️ 윈도우 사용자**: 기본 지원되지만, Chrome이 특이한 위치에 설치돼 있으면 안 될 수 있어요.
에러가 나면 Claude에게 "크롬 경로 못 찾는대"라고 말하면 해결해 줍니다.

---

## 1. 처음 한 번만 — 세팅 (5분)

1. 이 `coupang-contents` 폴더를 원하는 위치에 통째로 복사 (예: 바탕화면)
2. 터미널(윈도우: PowerShell)에서 그 폴더로 이동해 Claude Code 실행:
   ```
   cd 바탕화면/coupang-contents   ← 폴더를 둔 위치
   claude
   ```
3. Claude에게 그대로 입력:
   ```
   세팅해줘
   ```
4. "세팅 완료!"가 나오면 끝. (라이브러리 설치를 Claude가 알아서 합니다)

---

## 2. 매번 쓰는 법 — 링크 하나로 끝 (2~3분)

### ① 쿠팡 파트너스에서 링크 발급

쿠팡 파트너스(partners.coupang.com) → 상품 검색 → **링크 생성** → `https://link.coupang.com/a/...` 복사

### ② Claude에게 그대로 입력

```
이 링크로 쓰레드 글이랑 카드뉴스 만들어줘
https://link.coupang.com/a/XXXXXX
```

### ③ 기다리면서 알아둘 것

- **Chrome 창이 저절로 뜹니다 → 정상입니다!** (쿠팡 차단을 피하려고 진짜 크롬으로 접속하는 것)
- 뜬 크롬 창은 **건드리지 말고** 그대로 두세요. 크롤링이 끝나도 창은 떠 있어도 됩니다.
- 30초 정도면 크롤링 완료 → 이어서 Claude가 글을 쓰고 카드뉴스를 렌더링합니다.

### ④ 결과물 확인 — 미리보기 화면이 자동으로 뜹니다

`output/상품명_숫자/` 폴더에 생성:

| 파일 | 용도 |
|---|---|
| `preview.html` | **쓰레드 게시 미리보기 + 원클릭 복사** — 상단 버튼으로 페르소나 4명 글 전환 비교 |
| `threads_유진.md` 외 4종 | 페르소나별 쓰레드 본문 + 첫 댓글(링크·고지문구) 원본 |
| `slide_01~10.png` | 카드뉴스 (1080×1350, 4:5) — 쓰레드/인스타 첨부 |
| `caption.txt` | 인스타용 캡션 + 해시태그 |

- 쓰레드 글은 **페르소나 4명 버전으로 4개** 나옵니다 — 유진(26 자취러) / 살까말까(20대 중반 따지는 직장인) / 수현(35 워킹맘) / 태오(24 음슴체 드립). preview.html에서 버튼으로 비교하고 마음에 드는 것만 게시하세요. 계정을 여러 개 굴리면 페르소나별로 나눠 쓰기.
- 내 말투로 바꾸거나 페르소나를 추가하려면: `페르소나 바꿔줘 / 추가해줘`
- 카드뉴스를 **AI 광고 사진 버전**으로도: `광고형 이미지 버전으로도 만들어줘` (무료 Gemini API 키 필요, 연출 이미지(AI) 표기 자동)

---

## 3. 게시하는 법 (쓰레드 기준)

1. 쓰레드 앱 → 새 글 → `threads.md`의 **본문** 붙여넣기
2. 카드뉴스 PNG를 이미지로 첨부 (전부 또는 마음에 드는 것만)
3. 게시 직후 **내 글에 첫 댓글**로 `threads.md` 맨 아래 "첫 댓글에 달 내용" 블록 붙여넣기
   - 파트너스 링크 + 고지문구가 세트입니다

> ⚖️ **고지문구는 법적 의무입니다.** "이 포스팅은 쿠팡 파트너스 활동의 일환으로,
> 이에 따른 일정액의 수수료를 제공받습니다" — 링크 있는 곳엔 반드시 함께 게시하세요.
> (누락 시 공정위 제재 + 파트너스 계정 정지 사유)

---

## 4. 이런 요청도 됩니다

```
후킹을 더 자극적으로 바꿔줘
카드뉴스 표지 문구 바꿔서 다시 렌더링해줘
단점 부분을 더 부드럽게 써줘
유튜브 커뮤니티랑 블로그 글도 만들어줘      ← 4개 플랫폼 확장
```

## 5. 문제 해결

| 증상 | 해결 |
|---|---|
| "Access Denied"가 떴대요 | 떠 있는 크롬 창에서 쿠팡을 직접 30초 둘러본 뒤 "다시 크롤링해줘" |
| Chrome 창이 안 떠요 | Claude에게 "크롬 경로 확인해줘" (윈도우: 설치 경로가 다른 경우) |
| 가격이 안 잡혔어요 | "스크린샷 보고 가격 채워줘" (크롤 폴더에 화면 캡처가 저장돼 있음) |
| 카드뉴스 글자가 넘쳐요 | "N번 슬라이드 글자 줄여서 다시 렌더링해줘" |

## ⚠️ 운영 주의

- 같은 계정으로 **하루에 수십 개씩 도배하지 마세요** — 쓰레드 알고리즘이 판매성 계정을 억제합니다. 하루 1~3개 권장.
- 숫자(가격·할인율·리뷰 수)는 크롤링 시점 기준입니다. 게시 전에 가격이 바뀌었는지 한 번 확인하세요.
- 리뷰 인용은 원문 그대로만. 과장·윤색해서 붙이면 허위광고 리스크가 있습니다.
