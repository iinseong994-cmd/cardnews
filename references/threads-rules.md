# Threads 글쓰기 룰 (2026년 4월 기준, 한국 사용자 타겟)

Threads용 포스트를 만들 때 항상 적용하는 강제 룰. 변환 시작 전 반드시 이 파일을 다시 읽는다.

---

## 1. 글자수 / 길이

- **단일 포스트 최대: 500자** (링크는 카운트 제외)
- **Text Attachment**로 본문 안에 최대 10,000자 추가 가능 (접기/펼치기 "Read more" 형태)
- **권장 길이: 1 포스트당 280~450자**. 한 화면에 다 들어오는 길이(약 13줄, 줄당 36자)가 체류시간 우위
- 길면 **무조건 스레드 체인으로 분할**

---

## 2. 알고리즘 노출 원리 (2026 업데이트)

- **체류 시간(Reading Time)** 이 1순위 지표. 좋아요보다 "얼마나 오래 읽었는가"가 더 중요
- **Reply Depth(대화 깊이)** 가 2순위. 좋아요 100개보다 의미 있는 답글 10개가 노출에 유리
- **초기 30분 인게이지먼트 속도**가 바이럴 여부 결정 (30분 안에 좋아요 50개 > 24시간 100개)
- 외부 링크는 본문 노출에서 **리치 킬러**. 링크는 반드시 **첫 댓글(대댓글)에 고정**
- "좋아요/팔로우/공유해주세요" 노골적 요청은 **알고리즘 페널티**
- 판매성·광고성 톤도 알고리즘이 억제

---

## 3. 후크 / 오프닝 (첫 줄 = 헤드라인)

첫 줄에서 스크롤을 멈춰야 함. 3가지 패턴 중 하나 사용:

| 패턴 | 예시 |
|---|---|
| **도발적 단언** | "스레드에서 팔로워 1만은 의미 없다" |
| **호기심 질문** | "왜 내 글은 20명이 보고 끝날까?" |
| **공감 한 줄** | "오늘도 기획 3시간, 남은 건 버린 초안 5개" |

- **12~20자 내외**, 짧게
- 이모지는 첫 줄에 1개까지만
- 결과보다 **과정/실패/진짜 감정**이 더 잘 먹힘 (Raw 콘텐츠 선호)

---

## 4. 스레드 체인 전략

- **멀티 포스트(2~5개)** 가 단일 포스트보다 체류시간 · Reply Depth에서 우세
- **최적: 3~4 포스트 체인**
- 각 포스트가 새로운 포인트를 추가해야 함 — 단순 분절 X
- 끊는 위치: **호기심 갭이 생기는 지점** ("근데 여기서 반전이 있어 →")
- 마지막 포스트는 **질문/의견 요청**으로 마무리해 답글 유도

### 체인 템플릿

```
[1편] 후크 + 문제 제기 (280~400자)
  └─ "근데 진짜 이유는 따로 있어 ↓"

[2편] 핵심 인사이트 1 (280~400자)
  └─ "이것도 알아두면 좋은 게..."

[3편] 핵심 인사이트 2 + 사례 (280~400자)
  └─ "마지막으로 너희 의견이 궁금한 게 있는데"

[4편] 질문형 CTA (200~350자)
```

---

## 5. CTA 룰

- **질문형 · 의견 요청형**이 효과적: "너는 어때?", "이거 공감돼?", "반대 의견도 궁금"
- **CTA는 1개만**. 여러 개 섞으면 전환율 하락
- 금지: "좋아요 눌러줘", "팔로우해줘", "공유해줘" (알고리즘 억제)
- 추천: "댓글로 너의 케이스 알려줘" (답글 유도)

---

## 6. 해시태그 (Topic Tag)

- Threads는 **포스트당 Topic Tag 1개만 허용**. # 없이 파란색 링크 형태
- **2개 이상은 스팸 판정**, 노출 제한
- Topic Tag 있는 포스트가 평균 조회 수 더 높음
- 인스타에서 크로스포스팅 시 해시태그는 Threads에서 숨김 처리

---

## 7. 이모지 / 줄바꿈 (가독성)

- **이미지 포함 시 +60%, 영상 +59% 인게이지먼트**
- 줄바꿈으로 공백 줄 적극 활용 (한 단락 2~3줄 이내)
- 이모지는 포스트당 **2~4개**. 줄 시작 · 강조점에만
- 불릿(•, -, 1.)로 리스트화하면 체류시간 상승

---

## 8. 인스타그램과의 차이 (크로스포스팅 주의)

| | 인스타그램 | Threads |
|---|---|---|
| 중심 | 비주얼 | 텍스트 |
| 톤 | 완성된 지식 전달 | 날것의 생각/과정/질문 |
| 해시태그 | 최대 30개 | 1개 (Topic Tag) |
| 어조 | 존댓말 가능 | **반말 기본** |
| CTA | DM Send | 질문 답글 |

같은 원고라도 **톤 조정 없이 그대로 올리면 양쪽 다 실패**.

---

## 9. 2026년 한국 사용자 트렌드

- 한국 MAU **692만** (X 757만 턱밑 추격), 2030 + 직장인/전문가층 급증
- **반말 문화가 기본 톤**. 존댓말은 거리감 → 반응률 하락
- 잘 먹히는 3가지 포맷:
  1. **일기형/고백형**: "오늘 사수한테 혼난 얘기 들어볼래?" — 공감 기반
  2. **토론형/단언형**: "~는 틀렸다고 생각함" — 댓글 싸움 유도 → Reply Depth ↑
  3. **정보형(Raw)**: 완성된 가이드가 아닌 "내가 어제 알게 된 것" 형태의 쪼개진 팁
- **"라이팅힙(Writing-hip)"** 트렌드: 글쓰기 자체가 힙한 행위로 소비됨 → 문장력/리듬감 있는 짧은 글 선호
- 최적 발행: **화~금 오전 7~9시**, 최상은 **수요일 오전 7시**. 일요일 회피

## 10. 자동 검증 체크리스트

작성 후 항상 자가 검증:

- [ ] 단일 포스트가 500자 이내, 권장 280~450자인가?
- [ ] 첫 줄(12~20자) 후크가 3가지 패턴 중 하나인가?
- [ ] 체인이라면 3~4편 구조이고 각 편이 독립 포인트를 가지는가?
- [ ] 끊는 위치가 호기심 갭인가? (단순 분절이 아닌가)
- [ ] CTA가 질문형 1개인가? "좋아요/팔로우" 요청 없는가?
- [ ] Topic Tag가 1개 이하인가?
- [ ] 톤이 **반말** 기본인가? (존댓말 X)
- [ ] 외부 링크는 본문 밖(첫 댓글 자리)으로 뺐는가?
- [ ] 단락이 2~3줄 단위로 끊어져 있는가?

체크리스트 1개라도 실패하면 다시 쓴다.
