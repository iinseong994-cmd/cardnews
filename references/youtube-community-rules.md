# YouTube 커뮤니티 글쓰기 룰 (2026년 기준)

YouTube 커뮤니티(=게시물) 탭용 글을 쓸 때 항상 적용하는 강제 룰. 변환 시작 전 반드시 이 파일을 다시 읽는다.

---

## 1. 글자수 / 길이 제한

- **공식 최대**: 텍스트 전용 1,400자, 일부 옵션 시 최대 7,700자.
- **실질 핵심 구간 = 첫 288자**: 이 지점에서 "더보기(Read more)" 컷오프가 발생. 후크/핵심 메시지/CTA는 **반드시 이 안**에 들어가야 한다.
- **권장 길이**: **150~280자**. 모바일 한 화면에서 "더보기" 누르지 않아도 다 보이는 분량이 가장 반응이 좋다.
- **투표(Poll)**: 옵션당 최대 65자, 2~5개 선택지. 퀴즈 답변은 최대 80자.

---

## 2. 노출 알고리즘

- 노출 경로: **구독자 홈피드 → 구독 피드 → Shorts 피드** → (반응 좋으면) 비구독자 홈피드까지 확장.
- **알림은 3일에 1회로 제한**. 매일 올리면 알림이 안 가니, 중요한 글 하나에 집중.
- 알고리즘이 보는 신호: **좋아요, 댓글, 투표 참여율, 체류 시간**. 채널 전체 참여도 점수에 합산되어 영상 추천에도 간접 영향.
- 2026년 알고리즘 핵심어: "시청자 만족도(Satisfaction)". 커뮤니티에서 쌓는 실질 참여(댓글/투표)가 과거보다 더 중요해졌다.

---

## 3. 목적별 사용 패턴

| 목적 | 포맷 | 핵심 |
|---|---|---|
| **영상 홍보** | 영상 첨부 + 짧은 텍스트 | 업로드 후 24시간 내, "왜 봐야 하는지" 1줄로. 판매조 금지 |
| **떡밥/티저** | 이미지(썸네일 초안/BTS) + 호기심 질문 | "인사이더 감각" 유발. 충성 구독자가 많은 채널에 특히 효과 |
| **투표** | Poll (2~5개) | 텍스트 대비 **3~4배 상호작용**. 가장 알고리즘 친화적 |
| **단순 소통** | 텍스트 + 질문 1문장 | 가장 안전한 기본값. 댓글 유도형 1문장 질문 |

대본의 톤이 정보형이면 떡밥/투표, 스토리/공감형이면 소통/투표, 광고형이면 영상 홍보로 매핑.

---

## 4. 후크 / 첫 줄 전략

- **첫 12~20자 = 홈피드 카드 미리보기**. 여기서 클릭 여부 결정.
- 후크를 288자 밖으로 밀면 참여도 급락. **front-loading 필수**.
- 효과적인 오프너 패턴:
  - **호기심형**: "이 중 하나는 무조건 틀립니다"
  - **숫자형**: "3일 동안 이거 하나만 바꿨더니"
  - **질문형**: "여러분은 어느 쪽?"
  - **고백형**: "솔직히 말할게요"
  - **반전형**: "사실 ~가 아니었어요"

---

## 5. 이미지 / 링크 / GIF / 투표 활용

- **이미지**: 포스트당 최대 10장. 썸네일 초안 / 현장 사진 / BTS가 강력. 이미지 + 질문 조합은 참여도 약 2배.
- **GIF**: 피드에서 자동재생되어 시선 점유율 높음. 리액션/티저에 적합.
- **투표(Poll)**: 가장 반응 높은 포맷. 텍스트 전용 대비 **3~4배 상호작용**.
- **링크**: 외부 링크는 클릭률 낮음. 자사 영상 첨부(임베드 썸네일)를 우선.

대본 변환 시 이미지/GIF는 직접 만들 수 없으니 `[이미지: 설명]` 자리표시자로 표기.

---

## 6. CTA 룰

- **판매조 금지**, **선택형 권장**: "좋아요 눌러주세요" < "여러분은 A? B?"
- 효과적 CTA:
  - "투표로 알려주세요"
  - "댓글에 ○○ 적어주세요"
  - "다음 영상 주제 골라주세요"
  - "정답은 영상에서 공개합니다" (영상 클릭 유도)
- 구독 요청은 잘 안 먹힘 (이미 구독자에게 노출). 대신 **"알림설정"**이 실질적.
- 영상 클릭 유도 시 **결과/혜택 1가지만** 명시.

---

## 7. 해시태그 / 이모지

- **해시태그**: 1~3개가 적정. 검색 비중 낮아 필수는 아님. **브랜드 해시태그 1개**를 꾸준히 쓰는 것이 가장 효과적.
- **이모지**: 1~3개. 문장 앞이나 줄바꿈 마커로. 한국 채널은 과다 사용 시 "광고 같다" 인식 → 절제.

---

## 8. 포맷팅 (줄바꿈 / 단락)

- 모바일 1줄 약 20자 기준. **2~3줄마다 빈 줄**.
- "벽글"(긴 본문 한 덩어리)은 이탈률 급증.

### 권장 4단 구조

```
[1줄 후크 — 20자 내]

[본문/맥락 — 2~3줄]

[떡밥/핵심 정보 — 1~2줄]

[CTA 또는 질문 — 1줄]
```

전체 분량이 280자를 넘지 않도록.

---

## 9. 2026년 한국 채널 트렌드

- **'게시물' 탭으로 명칭 변경**(2025년) 후 구독자도 글 올릴 수 있게 되어 **쌍방향 커뮤니티화** 진행 중. "대답해주는 글"이 잘 먹힘.
- **투표 + 영상 예고** 조합이 한국 채널 최고 CTR.
- **BTS/썸네일 A안 B안 투표**가 떡밥 공식.
- **주 2~4회** 업로드가 최적. 매일 쓰면 오히려 피로도↑.
- **500 구독자 미만**은 커뮤니티 탭 해금 안 됨(2026 유지).
- "광고/홍보 톤"보다 "친구가 말 거는 톤"이 만족도 알고리즘에 유리.

---

## 10. 자동 검증 체크리스트

작성 후 항상 자가 검증:

- [ ] 첫 288자 안에 후크/핵심/CTA가 다 들어갔는가?
- [ ] 전체 길이가 150~280자인가?
- [ ] 첫 12~20자(미리보기 컷)가 클릭을 유발하는가?
- [ ] CTA가 "선택형"인가? "판매형"이 아닌가?
- [ ] 2~3줄마다 줄바꿈으로 가독성을 확보했는가?
- [ ] 해시태그 1~3개, 이모지 1~3개 안인가?
- [ ] (영상 홍보형이면) 결과/혜택 1가지를 명시했는가?

체크리스트 1개라도 실패하면 다시 쓴다.
