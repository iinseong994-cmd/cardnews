# 후킹멘트 규칙 — 카드뉴스 표지·쓰레드 첫 줄

> 출처: Notion 「100만 후킹멘트 모음집 (1)」 (개인 워크스페이스)
> 카드뉴스 **표지 후크**와 쓰레드 **첫 줄**을 만들 때 반드시 이 파일을 읽는다.

## 쓰는 법 (절차)

1. 상품 데이터(`summary.md`·`review.md`·상세페이지)에서 **놀라운 사실 1개**를 먼저 찾는다
2. 그 사실을 **서로 다른 분류 3개**로 후크 후보를 만든다 — 같은 분류로 3개 뽑지 않는다
3. 각 후보 옆에 **분류 번호**를 적어 사용자에게 제시하고 고르게 한다
4. 고른 후크는 **페르소나 말투로 번역**한다 (정원=존댓말, 하루=단문, 살까말까=반말 결론형…)

**길이**: 12~20자. 제품명·브랜드명·가격은 후크에 넣지 않는다.

---

## 6가지 심리 분류

| # | 분류 | 심리 | 상품 카드뉴스 적합도 |
|---|---|---|---|
| 1 | **문제언급** | 고통 회피 | ★★★ 원문에 "전환율 상" 명시 |
| 2 | **이득제시** | 보상 추구 | ★★★ 꿀팁·가성비형이 안전 |
| 3 | **부정형** | 인지 충돌 | ★★★ 통념 반박이 제일 잘 먹힘 |
| 4 | **정보갭** | 자이가르닉 | ★★☆ 수치형은 창작 위험 |
| 5 | **타겟언급** | 칵테일 파티 | ★★★ "이런 분만 보세요" |
| 6 | **도전형** | 도파민 루프 | ★☆☆ 장기 실험 콘텐츠용, 상품 소개엔 부적합 |

---

## 1. 문제언급 (고통·결핍 자극 → 전환율 상)

> 성공 요소: **소비자의 결핍을 얼마나 잘 드러냈는가** (시각적·언어적)

| 원본 템플릿 | 전환용 멘트 (후크 뒤에) |
|---|---|
| (문제언급) 습관 TOP7 (feat. 00년차 000) | |
| ~~하고 싶은데 ~~하기 싫다고요? 이렇게만 해보세요 | |
| (문제언급)이 있으시다면 이렇게 해보세요 | |
| (부정적 상황언급) 대처법 알려드릴게요 | 특히 3번째가 진짜 충격적이니 한번 끝까지 봐주세요 |
| ~~가 도저히 안 된다면 이 (숫자)가지 ~~를 확인해보세요 | 제가 이 방법으로 ~~를 해냈습니다 |
| ~~할 때 ~~가 도저히 안 된다면 ~~를 해보세요 | ~~만 잘해도 (이득제시)은 됩니다 |
| (문제언급) 이거 안 하면 더 심해집니다 | |
| ~~할 때 필수 ~~ | |

**상품 적용 예**
- 손선풍기 → "아직도 미지근한 손선풍기 쓰세요?"
- 주방세제 → "과일 그냥 물로만 씻고 계셨다면"

## 2. 이득제시 (욕망 자극)

| 원본 템플릿 | 전환용 멘트 |
|---|---|
| ~~하는(되는) 꿀팁 하나 알려드릴게요 | ~~로 자동화할 수 있습니다 (간단함·편리함 강조) |
| 10분 만에 ~~할 수 있는 꿀팁 하나 알려드릴게요 | |
| ~~만원대 뽕뽑는 초가성비 (제품 카테고리) | |

**상품 적용 예** — 가격을 카드에 안 쓰기로 했으므로 "만원대" 류는 첫 댓글로 돌린다.

## 3. 부정형 (인지 충돌·통념 반박)

| 원본 템플릿 |
|---|
| 절대절대 금지 (제품·행동) 3가지 |
| 절대로 (알려줄 내용) 없이 (행동) 하지 마세요 |
| 제발 ~~한 사람과 (행동)하지 마세요 |
| (두려운 상황) 오게 만드는 최악의 습관 20가지 |
| 절대로 사용하면 안 되는 (주제) 5가지 |
| (행동)하는 게 너무 비싸다고 말하지 마세요 |

**상품 적용 예**
- 손선풍기 → "선풍기인데 만지면 차갑습니다" *(실제 채택)*
- 주방세제 → "설거지만 하는 세제가 아니에요" *(실제 채택)*

## 4. 정보갭 (미완성 긴장감·FOMO)

| 원본 템플릿 |
|---|
| ~~명 중에 ~~명은 ~~를 잘못 알고 있어 |
| 10초 만에 남들과 다르게 (목표)하는 법 |
| (시간)분에 (개수)개 팔린 제품 |
| 현재 (수치)%의 사람들은 (행동)을 잘못하고 있습니다 |
| 저는 이걸 깨닫는 데까지 (기간)이 걸렸지만 30초 안에 정리해드리겠습니다 |
| (흔히 하는 행동) 함부로 하면 안 되는 이유 알아? |
| 한국인 (수치)%가 당하는 (부정적 결과) |
| (전문가)들은 이 영상 싫어할걸요? |
| 아직도 (흔히 하는 행동)를 한다고? |
| (행동) 하느라 돈 쓰지 마세요 |
| (전문가)들은 절대 하지 않는 습관 |

**상품 적용 예**
- 주방세제 → "주방세제에도 등급이 있는 거 아셨어요?" *(캡션에 실제 사용)*

## 5. 타겟언급 (칵테일 파티 효과)

원본 문서 상단 분류에만 있고 별도 DB는 없다. 패턴:
- 조건 지정형 — "팔로워 1000명 이하인 분"
- 직업/나이 지정형 — "직장인 5년차만 보세요"
- 상황 지정형 — "자취 처음 시작하는 분"

**상품 적용 예**
- 손선풍기 → "밖에서 일하는 분만 보세요"
- 주방세제 → "아이 식기 따로 닦는 분만"

## 6. 도전형 (도파민 루프)

| 원본 템플릿 |
|---|
| (낮은 위치의 본인) 가 (기간) 안에 (높은 목표)를 할 수 있을까요? |
| (기간) 동안 (행동 3가지) 하면 (변화 주체)가 얼마나 변할까 |
| (행동)하기 1일차 / (행동 및 목표) 전후 비교 |
| ~~에서 ~~원짜리 ~~를 사면 어떻게 될까? |
| (기간) 동안 (행동)을 해봤습니다 |

> 특이사항(원문): **돈·사업·피트니스·변화**에 적용 시 좋음
> **상품 소개 카드뉴스에는 잘 안 맞는다.** 직접 장기 사용해본 게 아니면 쓰지 않는다.

## (참고) 사건형 훅

| 원본 템플릿 | 구조 |
|---|---|
| (행동)을 했다. 근데 (부정적 상황)이 되었다 | 상황 + 반전 및 문제 발생 |
| 저 (부정적 사건)하고 왔어요 | |
| 나는 최근에 (흔한 행동)을 했다. 근데 왜 (부정적 사건)가 됐을까? | 사건 발생 → 반전 |
| (무언가 시도)했는데 (반전+부정적 결과)가 나왔다 | 평범한 시도 + 반전 |
| [권위·유명한 곳]에서 연락이 왔다 | |

→ **페르소나 에피소드**로만 쓴다. 겪지 않은 사건을 지어내지 않는다.

## 🚫 이 문서에서 **쓰면 안 되는** 패턴 (쿠팡 파트너스 기준)

원본에는 조회수용 클릭베이트가 섞여 있다. 아래는 **표시·광고법 위반이거나 프로젝트 사실성 규칙 위반**이라 그대로 쓰지 않는다.

| 패턴 | 왜 안 되는가 |
|---|---|
| "한국인 90%가 발암물질을 먹고 있었습니다" / "(수치)%가 당하는" | **크롤 데이터에 없는 통계 창작** |
| "(시간)분에 (개수)개 팔린 제품" | 판매 수량은 확인 불가. 리뷰 수·평점만 쓴다 |
| "선착순·예약판매·기간한정·재고 소진" | 확인 안 된 **판매 조건 창작 = 허위 표시** |
| "BTS가 쓰는 ~" / "장원영 샵에서 쓰는" | **실존 인물 언급** — 초상·퍼블리시티권 문제 |
| "죽은 ~도 살리는 음식" / "먹으면 하늘나라 가는" | 건강 효능 단정. 특히 식품·건강기능식품은 위험 |
| "무조건 사야 하는" / "후회 안 합니다" | 단정형 광고 톤. 전 페르소나 금지 사항 |

**대체 원칙**: 숫자가 필요하면 **크롤 데이터**(리뷰 수·평점·가격·할인율)나 **상세페이지 표기 스펙**에서만 가져온다.

## 후크 후보 제시 형식 (사용자에게 보여줄 때)

```
🪝 후크 후보
  ⓐ [3·부정형]  선풍기인데 만지면 차갑습니다
  ⓑ [1·문제언급] 아직도 미지근한 손선풍기 쓰세요?
  ⓒ [5·타겟언급] 밖에서 일하는 분만 보세요
  ⓓ [4·정보갭]  손선풍기가 안 시원한 진짜 이유
```

분류가 겹치면 다시 뽑는다.
