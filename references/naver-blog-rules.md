# 네이버 블로그 글쓰기 룰 (2026년 기준)

네이버 블로그용 포스트를 만들 때 항상 적용하는 강제 룰. 변환 시작 전 반드시 이 파일을 다시 읽는다.

---

## 1. 핵심 알고리즘: C-Rank + D.I.A / D.I.A+

네이버 블로그 검색 노출은 2026년 현재도 **C-Rank → D.I.A → D.I.A+** 3단 랭킹. "키워드 맞추기" 시대는 끝났고, **"누가 썼는가(출처)"와 "실제 경험이 담겼는가"**가 핵심.

### C-Rank (출처 = 블로그 계정 전체 신뢰도)

평가 비중:
- **주제 전문성 40%** — 한 블로그가 한 주제에 집중될수록 가산점. 잡블로그는 불리.
- **활동 지속성 30%** — 꾸준한 업로드 (주 2~3회 권장).
- **사용자 반응 20%** — 체류시간, 스크랩, 공감, 댓글, 재방문.
- **콘텐츠 품질 10%** — 문서 단건의 품질.

> **운영 원칙**: 한 블로그 = 한 카테고리. 주제를 섞으면 C-Rank 점수 분산.

### D.I.A (Deep Intent Analysis) — 문서 단건 평가

- 문서의 **경험 · 의도 · 독창성**을 딥러닝으로 평가
- "검색자의 의도를 실제로 해결해주는가"를 본다
- 타 블로그와 중복 문장 비율이 높으면 감점

### D.I.A+ (2023 업데이트 ~ 현재)

- **딥 매칭**: 동의어 · 관련어까지 의미 단위로 매칭
- **패턴 분석**: 어뷰징 패턴(반복문, 키워드 스터핑) 자동 탐지
- **동적 랭킹**: 실시간 사용자 반응(CTR, 체류시간)에 따라 순위 재조정

---

## 2. 글자수 / 본문 길이

| 항목 | 값 |
|---|---|
| **본문 글자수 (공백 포함)** | **1,500~2,000자** (최소 마지노선 1,000자, 최적 1,500~3,000자) |
| **너무 짧으면** | 600자 이하는 저품질 신호 |
| **너무 길면** | 3,500자 넘기면 체류시간 대비 이탈 증가 |
| **키워드 개수** | 메인 + 세부 합쳐 **5~6개** |
| **키워드 밀도** | 본문 전체의 **1~2%** (2,000자 기준 메인 키워드 3~5회) |

---

## 3. 제목 작성 룰

- **전체 길이: 공백 포함 20~25자 이내** (모바일 검색결과 잘림 방지)
- **메인 키워드를 제목 맨 앞에** 배치 (위치 뒤로 갈수록 SEO 점수 하락)
- 경쟁 글과 차별화되는 **구체적 수치/연도/사례** 삽입 (예: "2026", "7가지", "실제 후기")
- **후킹 공식**: `[키워드] + [숫자/연도] + [감정/결과 단어]`
  - 예: "INFP 연애 특징 7가지 (2026 최신)"
- **본문이 제목을 배신하면 안 됨** (클릭 후 이탈 = D.I.A+ 감점)

---

## 4. 본문 구조

네이버 에디터는 H2/H3 대신 **소제목 블록(인용구/강조)** 으로 단락 구분. 그래도 "의미적 H2/H3" 구조로 쓰는 것이 D.I.A에 유리.

### 권장 구조 (1,500~2,000자 기준)

1. **도입 (150~250자)** — 검색자 고민을 첫 줄에 바로 던지기. "~때문에 고민이시죠?"
2. **본문 블록 3~5개** — 각 블록 300~400자 + 이미지 1장
3. **마무리 (150~200자)** — 핵심 요약 + 질문으로 댓글 유도

### 문단 규칙 (모바일 최우선)

- **한 문단 3~4줄 이내** (모바일 기준). 벽 텍스트 금물.
- 문단 사이 **빈 줄 1줄**.
- 중요 문장은 **굵게/색상** 강조 (한 포스트에 3~5회 이내)
- **동의어 · 관련어**를 의도적으로 섞기 ("MBTI" → "성격유형", "심리검사"). D.I.A+ 딥 매칭 가산점.

---

## 5. 이미지 / 사진

| 항목 | 권장값 |
|---|---|
| **본문 이미지 개수** | **6~13장** (상위노출 1~5위 평균치) |
| **배치** | 문단 사이마다 1장. 텍스트 300자당 이미지 1장 |
| **직접 촬영 사진** | 스톡보다 가중치 높음 (D.I.A "경험" 신호) |
| **중복/퍼온 이미지** | 감점. 같은 이미지 재사용 금지 |
| **썸네일(대표이미지)** | 16:9 제작, 중요 요소는 1:1 안쪽 |
| **alt 텍스트** | 네이버는 HTML 수정 불가 → **이미지 하단 캡션**으로 키워드 자연 노출 |

→ 변환 시 사진은 직접 만들 수 없으니 `[사진: 설명 — 가능하면 직접촬영]` 자리표시자로 표기.

---

## 6. 태그 / 카테고리

- **태그는 상위노출 직접 영향 없음** (색인 · 분류 용도)
- **5~10개 이내** 권장. 10개 넘기면 어뷰징 느낌
- 메인 + 세부 키워드 + 브랜드명 조합
- **카테고리는 주제별 세분화** — C-Rank "주제 전문성 40%"에 직결

---

## 7. 체류시간 / 후킹 / 가독성

**체류시간 목표: 3분 이상** (상위노출 평균).

### 첫 1~3줄이 체류시간의 95% 결정

후킹 패턴:
- **고민 직격**: "INFP인데 연애할 때 왜 이렇게 힘들까요?"
- **충격 수치**: "INFP 10명 중 8명이 겪는 연애 실수"
- **질문형**: "당신도 이런 적 있지 않나요?"

### 체류시간 증대 장치

- 본문 중간 **질문 던지기** → 댓글 유도
- **목록형/번호형** 구조 (스캔 독해 유리)
- 동영상/움짤 삽입 시 재방문율 +15%

---

## 8. 금기 사항 (저품질 직행)

네이버는 2026년 AI 대량 생성글을 강하게 필터링 중. 즉시 제재:

1. **키워드 스터핑** — 같은 키워드 부자연스럽게 반복
2. **복붙 · 유사문서** — 타 블로그와 문장 일치율 높으면 D.I.A+ 감점
3. **광고 · 홍보 과다** — 본문의 30% 이상이 홍보성
4. **AI 티 나는 기계적 문체** — "~에 대해 알아보겠습니다", "~는 다음과 같습니다" 같은 GPT 특유 문장 반복
5. **어뷰징 태그** — 본문과 무관한 인기 키워드 태그
6. **숨김 텍스트 / 흰색 폰트** — 즉시 저품질
7. **짧은 글 대량 발행** — 500자 미만 글을 하루 여러 건

---

## 9. 2026 최신 트렌드: "사람이 쓴 진짜 글"

2026년 3월 코어 업데이트 이후 핵심:

> **AI로 썼더라도, 사람이 실제 경험을 검토 · 보강한 글**은 순위 상승. **기계가 찍어낸 글은 하락**.

### AI 패널티 회피 원칙 (필수)

- **1인칭 경험 문장** 필수 ("제가 직접 해봤는데", "작년에 ~했을 때")
- **구체적 수치 · 고유명사** ("3일차에", "홍대 OO카페에서")
- **실제 사진** 최소 2~3장 (스톡/생성 이미지 제외)
- **지역 · 시간 · 감정** 디테일
- **GPT 기본 문체 전면 금지** ("~에 대해 알아보겠습니다" ❌ → "오늘은 ~얘기할게요" ✅)
- **공신력 있는 기관보다 더 구체적**인 정보가 상위노출. "식약처 공지"보다 "내가 먹어보고 3일간 기록한 변화"가 이긴다.

## 10. 자동 검증 체크리스트

작성 후 항상 자가 검증:

- [ ] 본문이 1,500~2,000자 인가?
- [ ] 제목이 25자 이내 + 메인 키워드가 맨 앞인가?
- [ ] 메인 키워드 밀도가 1~2% 안인가?
- [ ] 도입부 첫 1~3줄이 후킹(고민/수치/질문)인가?
- [ ] 본문 블록이 3~5개로 나뉘고 각 300~400자인가?
- [ ] 이미지 자리표시자가 6~13개 들어갔는가?
- [ ] 한 문단이 모바일 4줄 이내인가?
- [ ] 굵게 강조가 3~5회 이내인가?
- [ ] **1인칭 경험 문장**이 들어갔는가? ("제가", "작년에", "직접")
- [ ] **구체적 수치/고유명사**가 들어갔는가?
- [ ] GPT 기본 문체("~알아보겠습니다", "~다음과 같습니다") 안 썼는가?
- [ ] 동의어/관련어를 섞었는가? (D.I.A+ 딥 매칭)
- [ ] 태그 5~10개 인가?
- [ ] 마무리에 댓글 유도 질문이 있는가?

체크리스트 1개라도 실패하면 다시 쓴다.

---

## 11. 핵심 요약 3줄

1. **1,500~2,000자 / 이미지 6~13장 / 제목 25자 이내 + 키워드 맨앞 / 태그 5~10개**
2. **C-Rank = 블로그 주제 전문성, D.I.A+ = 문서의 경험 · 독창성. 둘 다 "1인칭 경험 디테일"로 공략**
3. **GPT 기본 문체 금지, 구어체 + 구체적 수치/고유명사/감정 삽입 필수**
